# Frontend — DispatchAI Dashboard

This is the admin dashboard for DispatchAI, an agentic AI voice system.

It provides a UI for managing AI-driven service bookings, monitoring calls, and configuring the AI agent.

---

## 🧠 What It Does

- View AI call logs and transcripts
- Manage bookings generated by the AI agent
- Configure services and availability
- Monitor system performance
- Handle subscription and billing

---

## ⚙️ Tech Stack

- Next.js (App Router)
- TypeScript
- Material UI
- Redux Toolkit
- React Query

---

## 🚀 Run Locally

```bash
pnpm install
pnpm dev
